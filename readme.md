# assembly

clawcrew was assembled intentionally using different ideas i found scattered across different products as foundational building blocks, including:
- slack-like visual ui platform where agents are first class citizens [like ando.so, kylon.io] but beyond buzz (by block) that only focussed on software teams
- multi-agent teams [like symphony by wix, usenaive.ai]
- agent organizational chart [like paperclip.ing]
- dedicated agent computers [like every always-on cloud machine like zo computer] and browser access [with browseruse/kernel.sh]
- custom agents [like skydive.com etc.]
- self-driving agents [like vorflux, obvious.ai]
- credentials broker [agentvault by infisical]
- workflows inbuilt [uses langflow/sim.ai/dify/n8n built in]
- overnight tasks [celery.dev]
- kanban boards, shifts and human metaphors
