## building it beyond
  ### i. beyond the ide

clawcrew covers
- beyond ephemeral microvms / firecracker microvms (persistent computers with celesto)
- beyond linux (other desktop and mobile operating systems with spawnables)
- beyond the ide (browser coverage with kernel.sh / browserbase / browseruse)

### ii. beyond just code

clawcrew covers building beyond code to
- boards [anytype / appflowy / affine]
- docs [docmost, tiptap.dev]
- tables & spreadsheets [baserow/nocodb/grist instead of airtable]
- slides [deckcraft @ getartcraft.com]
- kanbans [kan.bn / itsaplan.dev]
- datavisualization [plotly, chartjs, gephi, vizzuu, observablehq, d3]
- whiteboards [excalidraw, mermaidjs]
- design [penpot, opendesign, canva @ browser]
- notes [obsidian, notesnook, github.com/deepnotesapp]
- research [firecrawl, zotero, research@un.ms]
- search / retrieval [falkordb / hydradb / helixdb]

### iii. beyond just software [agents aren't shipped w all the tools, they get what they need based on scope to keep it light]

also covers vertical agents with the ability to build real world manufacturables, like:
- printed circuit boards
	- kicad native driving the computer / easyeda in the browser
 	- with code w tscircuit + wireviz harness
- manufacurable parametric cad (no mesh models w code)
	- openscad (for stls) for additive manufacturing
	- cadquery / build123d (for .step files) for cnc workflows for true b-rep

as well as making creative experiences, like:
- projection mapping & live visuals
	- hydra + webgl / three.js
	- openframeworks & cinder (c++)
	- touchdesigner (python)
	- glsl shadertoy, cables.gl
- spatial projections w webxr
	- a-frame
	- three.js
- music
	- strudel
	- sonic pi
	- tidalcycles
    - supercollider
- interactive installations
  - computer vision & pose tracking (mediapipe, opencv, yolo) w standard webcams / depth sensors (orbbec, redsense)
  - kinetic & robotic art
 
and useable creative assets like: 
- making pixel art that can be computationally generated art with:
	- adapted access to aseprite
	- pio-8 & tic-80 games inside single .p8 / .lua files
- kinetic typography
- blender shaders

or even bridging the two, with:
- vector graphics (essentially xml code)
	- p5.js / paper.js code
	- raw svg paths
that can be bridged to become physical world pen-plotter art via plotters like axidraw
